# 🛒 Comfy Store

Modern E-commerce frontend built with **React** & **Zustand**.

## ⚡ Key Features

- **Global State:** Managed via Zustand (persistent cart storage).
- **Dynamic Filters:** Search by category, company, and price range.
- **Adaptive UI:** Responsive design using Tailwind CSS & DaisyUI.
- **Theming:** Dark/Light mode support.

## 🛠 Tech Stack

React • Zustand • Tailwind CSS • DaisyUI • Lucide Icons
